# 安全模型

## 信任边界

本地导入目录、在线目录 JSON、预览、ZIP、PNG 及附带文档均不可信。程序只按用户操作访问所配置的在线宠物 HTTPS 地址，不执行脚本、不加载资产程序集、不解析 HTML，也不向应用安装目录复制资产。

## 在线边界

- 在线目录、预览和包地址必须是无凭据的绝对 HTTPS URL；客户端拒绝自动重定向，避免被降级到非 HTTPS 地址。
- 目录 JSON 最大 2 MiB、最多 500 项；名称、描述、作者、版本与 URL 均有限长。预览最大 4 MiB、宽高不超过 2048，且须通过 PNG 头和实际解码校验。
- ZIP 声明大小必须在 1 到 128 MiB 之间。下载同时核对 `Content-Length`（若提供）、实际字节数和 SHA-256；不匹配、中断或取消都会放弃事务。
- 下载先进入随机 staging。SHA-256 通过后仍必须进入共享 `PetPackageValidator`，目录 id 和 `spriteVersionNumber` 还须与包内结果一致，之后才允许 Assets 提交安装。
- 网络错误只更新在线页状态和日志，不卸载、隐藏或替换当前运行宠物。客户端不后台轮询目录，也不将目录内容当 HTML 或代码执行。

## 路径与 ZIP

- Manifest 路径必须非空、相对、无根路径、无 `..` 段，规范化后仍位于包根目录。
- ZIP 每一项在写入前规范化；拒绝逃逸、绝对路径、过多条目、超限单文件和超限总解压大小。
- 目录导入拒绝重解析点，复制后仍在 staging 中重新验证。
- staging 使用随机目录；失败或取消始终清理。
- 桌面安装器与 `sdc-pet-validator` 共用同一 staging 实现；CLI 只返回结构化结果，不写入正式宠物目录。

## 资源限制

第一版只解码 PNG；图片文件最大 64 MiB，Atlas 必须恰好为受支持的 1536×1872（sprite v1）或 1536×2288（sprite v2），解码后上限受固定像素数约束。ZIP 最多 256 个条目、总解压大小 128 MiB、单条目 64 MiB。

## 安装事务

新包在 staging 中通过全部验证后再移动到管理目录。同 ID 替换时，将旧目录先原子改名为备份，再移动新目录；第二步失败则恢复旧目录。资产不能覆盖应用文件。配置采用同目录临时文件、flush-to-disk 和原子替换；损坏配置重命名备份后恢复默认。

所有内置宠物 ID 都受删除与在线覆盖保护。删除当前的非内置宠物时，必须先成功切换到默认内置宠物；切换失败则保留原目录。删除非当前宠物不改变当前窗口。

## IPC

Named pipe 仅接受 `show`、`hide`、`settings` 与 `import <path>`；不调用 shell，不把文本当命令行执行。Pipe 限当前用户实例，导入路径仍进入完整资产验证流程。
