# 白荆科技宿舍走廊 v0.1.0-alpha.2

这是第二个早期公开版本，主要新增内置 Sweeper-EX 桌宠，并修复不同 PNG DPI 元数据和高 DPI 桌面下可能发生的动画帧放大、裁切问题。

## 下载

- `SeedDormitoryCorridor-0.1.0-alpha.2-win-x64-setup.exe`：当前用户安装包，无需管理员权限。
- `SeedDormitoryCorridor-0.1.0-alpha.2-win-x64-portable.zip`：免安装版，解压后运行 `SeedDormitoryCorridor.App.exe`。
- `SHA256SUMS.txt`：两个包的 SHA-256 校验值。

两个包都自带 .NET 运行时，不需要另行安装 .NET。免安装版仍会把配置、日志和导入的宠物保存到用户的 AppData，因此不是完全无痕的便携模式。

## 新增内容

- 新增 Sweeper-EX 作为第三个可选择的内置桌宠，可从托盘菜单与设置界面切换。
- Sweeper-EX 包含完整的 sprite v1 九行动画 Atlas，并使用与外部宠物相同的安全校验流程。
- 发布目录、免安装包和安装包现在都会包含 Sweeper-EX 资产。

## 修复与改进

- 修复 PNG 解码受物理 DPI 元数据影响的问题；Atlas 现在始终按照原始像素坐标一比一解码。
- 修复高 DPI 桌面上后备缓冲使用 `Display` 单位，导致动画帧被放大并裁掉右侧或底部的问题。
- Sweeper-EX 的内置 `spritesheet.png` 现在与审核后的透明原始 Sheet 完全一致，不再经过会改写 DPI 信息或损伤浅色服装像素的重复编码。
- 改进 Sweeper-EX 资产生成流程：已透明的标准 Atlas 直接复制；非透明预览只清理与画布边缘连通的中性背景；生成资产会更新时间戳以避免 `PreserveNewest` 留下旧文件。
- 增加 PNG DPI 无关解码、渲染像素坐标及内置 Sweeper-EX 资产回归测试。

## 已知限制

- 这是未经 Authenticode 签名的 alpha 版本，Windows SmartScreen 可能显示未知发布者警告。
- 当前只支持 Windows 11 x64，只显示一个宠物，只接受 PNG Atlas。
- 没有自动更新、在线商店或可执行插件。
- 真实透明、焦点、混合 DPI、多屏、Explorer 重启、睡眠唤醒及安装/卸载仍需在真实 Windows 桌面完成人工验收；自动化测试不能替代这些检查。
