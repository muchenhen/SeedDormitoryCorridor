# 白荆科技宿舍走廊 v0.1.0-alpha.1

这是项目的第一个早期公开版本，面向 Windows 11 x64。它已经包含桌宠运行、动画交互、托盘设置和安全宠物包导入的完整基础，但仍属于粗糙的 alpha 版本。

## 下载

- `SeedDormitoryCorridor-0.1.0-alpha.1-win-x64-setup.exe`：当前用户安装包，无需管理员权限。
- `SeedDormitoryCorridor-0.1.0-alpha.1-win-x64-portable.zip`：免安装版，解压后运行 `SeedDormitoryCorridor.App.exe`。
- `SHA256SUMS.txt`：两个包的 SHA-256 校验值。

两个包都自带 .NET 运行时，不需要另行安装 .NET。免安装版仍会把配置、日志和导入的宠物保存到用户的 AppData，因此不是完全无痕的便携模式。

## 首版内容

- 内置苏筱、田偌和小豆人宠物，支持安装和切换外部宠物包。
- 九种动画、点击/双击/拖拽交互和带权重、冷却的特殊 Idle。
- 分层透明窗口、逐像素命中、完全鼠标穿透、总在最前及多显示器/DPI 支持。
- 托盘菜单、设置、单实例、开机启动和本地状态保存。
- 对目录和 ZIP 宠物包执行路径、大小、格式和 Alpha 安全校验。

## 已知限制

- 这是未经 Authenticode 签名的 alpha 版本，Windows SmartScreen 可能显示未知发布者警告。
- 当前只支持 Windows 11 x64，只显示一个宠物，只接受 PNG Atlas。
- 没有自动更新、在线商店或可执行插件。
- 真实透明、焦点、混合 DPI、多屏、Explorer 重启、睡眠唤醒及安装/卸载仍需要持续扩大人工验证覆盖。
