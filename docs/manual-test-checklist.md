# Windows 人工验收清单

> 自动化测试不能证明以下真实桌面行为。发布前在 Windows 11 x64 的 Release self-contained 构建逐项勾选并记录机器/DPI。

## 分层窗口与交互

- [ ] 宠物背景真实透明，没有黑/白矩形或边缘黑边。
- [ ] 透明区域点击落到后方程序，身体区域可单击、双击和拖拽。
- [ ] 拖出窗口后仍保持捕获，松开可靠结束拖拽。
- [ ] 完全穿透时窗口不接收输入，并能从托盘恢复。
- [ ] 宠物不出现在任务栏和 Alt+Tab，显示时不抢当前输入焦点。
- [ ] 总在最前开关即时生效。
- [ ] 隐藏不退出，托盘显示能恢复；托盘退出后进程消失。

## 显示器与系统

- [ ] 主/副显示器间移动正常，包括左侧负坐标显示器。
- [ ] 100%/125%/150% 不同 DPI 显示器之间尺寸和命中正确。
- [ ] 拔除保存位置所在显示器后，宠物回到主屏工作区且部分可见。
- [ ] 睡眠/唤醒后动画、位置和托盘正常。
- [ ] Explorer 重启后托盘图标恢复。
- [ ] Windows 注销/关机保存状态并无异常阻塞。

## 资产与生命周期

- [ ] 全部九种动画逐项播放，帧序和完成跳转正确。
- [ ] 导入合法目录和 ZIP 成功；非法包一次展示全部问题。
- [ ] 同 ID 的替换/取消正确，模拟失败时旧宠物仍可用。
- [ ] 当前宠物文件损坏后重启可回退；运行中切换失败仍显示旧宠物。
- [ ] 单实例：第二次启动只激活已有实例，且 import 命令有效。
- [ ] 设置关闭不退出；缩放、渲染模式、阈值、Idle、启动项实时生效。

## 安装与资源

- [ ] 从 GitHub Release 下载安装包、免安装 ZIP 和 `SHA256SUMS.txt`，两个包的 SHA-256 均匹配。
- [ ] 免安装 ZIP 解压后可直接启动，且苏筱、田偌和 Sweeper-EX 三个可选内置宠物均存在，小豆人故障回退资源也存在。
- [ ] 当前用户安装、开始菜单、可选桌面快捷方式正确。
- [ ] 覆盖安装成功；卸载默认保留配置/宠物，选择清理时删除用户数据。
- [ ] Release 静置、隐藏、暂停时 CPU 接近空闲，无持续重绘。
- [ ] 连续运行/切换 30 分钟，GDI Objects 和内存无持续增长。
